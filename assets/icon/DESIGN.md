# note-sync App Icon

概念是「持續保存的一張筆記」。中央摺角文件代表 Markdown，兩段順時針箭頭代表 Git 同步與持續建立快照。只保留文件與同步兩種意象，不另疊搜尋符號。

## 色彩

| 用途 | Hex |
| --- | --- |
| 深海軍藍底、文件內文線 | `#102A38` |
| 冷白文件 | `#EDF6F8` |
| 藍灰摺角 | `#ACC9D4` |
| 青綠同步箭頭 | `#40D6B0` |

全圖採平面實色，不使用漸層、陰影、文字或外部字型。色彩避開紫色、奶油底與 terracotta。

## 形狀與背景

- 主圖為 `1024 × 1024` SVG，中央對齊。
- 深色圓角方底從 `(64, 64)` 開始，尺寸 `896 × 896`、圓角半徑 `208`。
- 文件使用圓角下緣與右上摺角，兩條粗短線保留小尺寸的筆記辨識度。
- 同步箭頭使用 `44` 單位粗線、圓頭與明確斷口，環繞文件而不穿過紙張。
- **選用透明外圍**：圓角方底以外為透明，方底內為不透明深色。PNG 保留 RGBA alpha，不帶白色底板。

## 產出與使用

- `icon.svg`：可編輯、可縮放主圖，無外部資源或內嵌點陣圖。
- `icon-1024.png`：1024 × 1024 主素材。
- `icon-256.png`：256 × 256 預覽素材。

PNG 依 SVG 幾何以 Pillow 在主素材的 4 倍尺寸（4096 × 4096）繪製，再用 Lanczos 縮至目標尺寸，以保留圓角與箭頭邊緣。

本組為彩色 App Icon 素材，尚未整合 App bundle 或產生 `.icns`。選單列若使用 template image，應另製透明背景的單色簡化版，不直接縮小此彩色圖示。
